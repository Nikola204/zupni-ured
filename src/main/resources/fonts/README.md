# Noto Sans za PDF

`NotoSans-Regular.ttf` je neizmijenjeni statički font iz projekta Noto:
https://github.com/notofonts/noto-fonts/blob/main/hinted/ttf/NotoSans/NotoSans-Regular.ttf

Preuzeto 17.09.2026. SHA-256:
`b85c38ecea8a7cfb39c24e395a4007474fa5a4fc864f6ee33309eb4948d232d5`

Licenca SIL Open Font License 1.1 priložena je u `OFL.txt`.
Font podržava hrvatske znakove i umeće se kao podskup u generirani PDF.
Smješten je izvan `static` direktorija: aplikacija ga ne izlaže kao javnu datoteku.
Ne zahtijeva instaliranje fonta na poslužitelju ni računalu korisnika.
